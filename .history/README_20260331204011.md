# Madurai Veeran — Personal Brand Website

A modern personal brand website for **Madurai Veeran**, a Tamil financial literacy advocate, investor, and wealth discipline mentor.

Built with [Next.js](https://nextjs.org/) (App Router) and custom Webflow-exported CSS/JS for animations.

## Tech Stack

- **Framework**: Next.js 16 (React 19, App Router)
- **Language**: TypeScript
- **Styling**: Webflow CSS + custom vanilla CSS
- **Animations**: GSAP, Swiper, Webflow Interactions

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or later
- npm (comes with Node.js)

### Install & Run

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```

## Firebase Form Storage Setup (Frontend Only)

This project stores submissions from:

- Contact form
- Meet Me form
- Consultation popup form

directly from the frontend into Firestore collection `form_submissions`.

### Built-in lightweight protection

- Firebase App Check (reCAPTCHA v3) support
- Hidden honeypot field on all forms
- Minimum fill-time check (blocks instant bot submits)
- Client-side submission throttle

### 1. Enable Firestore

- Open Firebase Console
- Create/enable Cloud Firestore for your project

### 2. Create Web App Credentials

- Open Firebase Console -> Project Settings -> General
- Create a Web App (if not already)
- Copy SDK config values into `.env.local`

### 3. Configure Environment Variables

Copy `.env.example` to `.env.local` and set:

- `NEXT_PUBLIC_FIREBASE_API_KEY`
- `NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN`
- `NEXT_PUBLIC_FIREBASE_PROJECT_ID`
- `NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET`
- `NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID`
- `NEXT_PUBLIC_FIREBASE_APP_ID`
- `NEXT_PUBLIC_RECAPTCHA_V3_SITE_KEY`

### 4. Enable App Check

- Open Firebase Console -> App Check
- Register your web app
- Select reCAPTCHA v3 provider
- Use the site key as `NEXT_PUBLIC_RECAPTCHA_V3_SITE_KEY`
- Enable App Check enforcement for Firestore after testing

### 5. Recommended Firestore Security Rules

Use strict rules that only allow creates for the expected shape:

```text
rules_version = '2';
service cloud.firestore {
	match /databases/{database}/documents {
		match /form_submissions/{docId} {
			allow create: if request.resource.data.keys().hasOnly([
				'formType',
				'name',
				'email',
				'message',
				'createdAt'
			])
			&& request.resource.data.formType in ['contact', 'meet-me', 'consultation']
			&& request.resource.data.name is string
			&& request.resource.data.name.size() > 0
			&& request.resource.data.email is string
			&& request.resource.data.email.matches('^[^\\s@]+@[^\\s@]+\\.[^\\s@]+$')
			&& (
				request.resource.data.message == null ||
				request.resource.data.message is string
			);

			allow read, update, delete: if false;
		}
	}
}
```

### 6. Run

```bash
npm install
npm run dev
```

After this, form submissions will be saved in Firestore from the frontend.
