# Madurai Veeran — Personal Brand Website

A modern personal brand website for **Madurai Veeran**, a Tamil financial literacy advocate, investor, and wealth discipline mentor.

Built with [Next.js](https://nextjs.org/) (App Router) and custom Webflow-exported CSS/JS for animations.

## Tech Stack

- **Framework**: Next.js 16 (React 19, App Router)
- **Language**: TypeScript
- **Styling**: Webflow CSS + custom vanilla CSS
- **Animations**: GSAP, Swiper, Webflow Interactions

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18 or later
- npm (comes with Node.js)

### Install & Run

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm run start
```

## Firebase Form Storage Setup

This project now stores submissions from:

- Contact form
- Meet Me form
- Consultation popup form

through `POST /api/forms`, into Firestore collection `form_submissions`.

The endpoint now also includes:

- Cloudflare Turnstile bot protection
- Per-IP rate limiting (10 submissions per 10 minutes)

### 1. Create Firebase Service Account

- Open Firebase Console -> Project Settings -> Service Accounts
- Generate a new private key JSON file
- Copy values into environment variables

### 2. Configure Environment Variables

Copy `.env.example` to `.env.local` and set:

- `FIREBASE_PROJECT_ID`
- `FIREBASE_CLIENT_EMAIL`
- `FIREBASE_PRIVATE_KEY` (keep `\\n` in the key)
- `NEXT_PUBLIC_TURNSTILE_SITE_KEY`
- `TURNSTILE_SECRET_KEY`

### 3. Create Cloudflare Turnstile Keys

- Open Cloudflare Turnstile dashboard
- Create a widget for your site domain
- Add the generated site key and secret key to `.env.local`

### 4. Run

```bash
npm install
npm run dev
```

After this, form submissions will be saved in Firestore.
